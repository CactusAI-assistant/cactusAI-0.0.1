# Cactus — Голосовой ассистент на Python

**Cactus** — персональный голосовой ассистент на Python на MacOS.  
Позволяет управлять компьютером, открывать приложения, искать информацию и получать данные о погоде с помощью голосовых команд.
Иначе говоря - это аналог Jarvis из фильма **MARVEL Железный Человек**

---

## Возможности

### 1. Голосовое взаимодействие
- Распознаёт речь на русском языке.
- Отвечает голосом через синтезатор `pyttsx3`.

### 2. Погода
- Команда: `погода в [город]`
- Сообщает:
  - Описание погоды (солнечно, дождь и т.д.)
  - Температуру в градусах
  - Влажность воздуха
  - Скорость ветра

### 3. YouTube
- Команды:
  - `открой YouTube` — открывает главную страницу YouTube
  - `включи видео [запрос]` — находит первое видео по запросу и открывает его

### 4. Открытие приложений и сайтов (Способствует к редактированию)

| Команда | Действие |
|---------|----------|
| открой Telegram | Открывает Telegram Web или приложение |
| открой WhatsApp | Открывает WhatsApp Web |
| открой Discord | Открывает Discord (Mac: приложение, Windows: браузер) |
| открой Spotify | Открывает Spotify Web |
| открой Twitch | Открывает Twitch |
| включи браузер | Открывает Google Chrome |
| включи Яндекс | Открывает Yandex Browser |
| открой проект | Открывает PyCharm |
| открой CapCut | Открывает CapCut |
| включи музыку | Открывает стандартное музыкальное приложение |
| включи Finder | Открывает Finder (только Mac) |

### 5. Интернет-поиск
- Команда: `найди в интернете [запрос]`
- Открывает Google (или Яндекс) с результатами поиска.

### 6. Информационные команды

| Команда | Действие |
|---------|----------|
| какое время / который час | Сообщает текущее время |
| Cactus | Ассистент отвечает «Да, Сэр?» |
| пока / стоп / спасибо | Завершает работу ассистента |

### 7. Шутливые команды
- Например, `взлом` — ассистент отвечает шуткой.
